# RAG Demo

This folder contains the code and Jupyter notebooks for the Retrieval-Augmented Generation (RAG) section of the AI Engineering Full Course for Beginners.

## Topics Covered

- What is Retrieval-Augmented Generation (RAG)?
- RAG architecture and workflow
- Document loading and processing
- Text chunking
- Embeddings
- Vector databases
- Document retrieval
- Similarity search
- Generating answers using retrieved context
