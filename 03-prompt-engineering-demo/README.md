# Prompt Engineering Demo

This folder contains hands-on Python examples demonstrating practical prompt engineering techniques for working with Large Language Models (LLMs).

Prompt engineering is the process of designing effective prompts to guide an LLM toward producing useful, accurate, and consistent outputs.

## Prompt Engineering Techniques Covered

### 1. Basic Prompting

Introduces the fundamentals of writing prompts and demonstrates how different prompts can influence an LLM's responses.

📄 [`BasicPromptDemo.py`](./BasicPromptDemo.py)

### 2. Role, Task, and Context Prompting

Demonstrates how defining the model's role, task, and relevant context can make prompts clearer and improve the quality of responses.

📄 [`RoleTaskContextPromptDemo.py`](./RoleTaskContextPromptDemo.py)

### 3. Few-Shot Prompting

Demonstrates how providing examples in a prompt can guide an LLM to follow a desired pattern or format.

📄 [`FewShotDemo.py`](./FewShotDemo.py)

### 4. Chain-of-Thought Prompting

Demonstrates prompting techniques that encourage an LLM to work through a problem step by step.

📄 [`ChainOfThoughtDemo.py`](./ChainOfThoughtDemo.py)

### 5. Constrained Output Prompting

Demonstrates how prompts can be designed to control the structure and format of an LLM's output.

📄 [`ConstrainedOutputPromptingDemo.py`](./ConstrainedOutputPromptingDemo.py)

## Why Prompt Engineering Matters

Well-designed prompts can help you:

* Give the LLM clear instructions
* Provide relevant context
* Control the format of responses
* Improve consistency
* Guide the model toward specific tasks
* Build more reliable LLM-powered applications

These techniques are useful when building applications such as chatbots, RAG systems, AI agents, content generation tools, and other Generative AI applications.
